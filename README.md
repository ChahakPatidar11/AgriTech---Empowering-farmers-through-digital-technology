AgriTech – Empowering Farmers Through Digital Technology.

About the Project

AgriTech is a web-based agriculture project designed to help farmers access useful agricultural services through a digital platform. It provides a foundation for connecting farmers with information and services related to farming.

Features

- Farmer-focused agricultural platform
- Frontend web interface
- Backend API for application functionality
- MongoDB database integration
- Organized frontend and backend structure

Technologies Used

- Frontend: React, JavaScript, HTML, CSS
- Backend: Node.js, Express.js
- Database: MongoDB, Mongoose
- Tools: Visual Studio Code, Git, GitHub

Installation and Setup

1. Clone the Repository

git clone https://github.com/ChahakPatidar11/AgriTech---Empowering-farmers-through-digital-technology.git
cd AgriTech---Empowering-farmers-through-digital-technology

2. Start the Backend

Open a terminal and navigate to the backend folder:

cd Backend
npm install

Configure the required environment variables in a ".env" file, then start the backend using the command defined in its "package.json".

3. Start the Frontend

Open another terminal and navigate to the frontend folder:

cd Frontend
npm install
npm run dev

Open the local URL shown in your terminal.
